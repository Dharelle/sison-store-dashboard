GitHub Setup

Configure your GitHub connection to enable automatic data saving and backup.

How to Get Your GitHub Personal Access Token

  1. Go to GitHub Settings → Personal access tokens
  2. Click "Generate new token (classic)"
  3. Name: Sison Store Dashboard
  4. Expiration: No expiration (or 1 year)
  5. Select scope: repo (Full control of private repositories)
  6. Click "Generate token" and copy it
  7. Paste the token below (you won't see it again!)

⚠️ Security Notice

Your GitHub token will be stored in your browser's localStorage. This means:

  • Anyone with access to this browser can access your GitHub repository
  • Use a token with limited scope (only repo)
  • Consider creating a dedicated repository just for this dashboard
  • Clear your configuration if using a shared computer
